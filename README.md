# Student Marks Analyser

A simple python project that calculates Students marks, average, grade and pass/fail status.

## Features

- Accepts student's name
- Accepts marks for five subjects
- Calculates Total marks
- Calculates Average marks
- Assigns a grade
- Determines pass/fail status
- Saves students results to a csv file
